<h1 align="center">ZasaBoard</h1>

<p align="center">Interface desktop para gerenciar múltiplas sessões e perfis de jogos idle.</p>

## Recursos

- Cartões com grade adaptável, foco individual e ocultação.
- Perfis persistentes e contas vinculadas.
- Lives e Multitwitch por perfil.
- Controle de áudio, recarga e visualização por cartão.
- Alinhamento e espelhamento de cliques e rolagem.

## Instalar

1. Acesse a [Beta 2](https://github.com/lisarbjoao/ZasaBoard/releases/tag/v2.0.0-beta.9).
2. Baixe **ZasaBoard-2.0.0-beta.9-Setup.exe** e execute.
3. Abra **ZasaBoard Beta 2** pelo atalho da área de trabalho ou pelo menu Iniciar.

Requer Windows 10/11 de 64 bits e Microsoft Edge WebView2 Runtime. Não precisa instalar Python nem manter o VS Code aberto.

Para usar a versão portátil, baixe o ZIP, extraia a pasta completa e execute **ZasaBoardBeta.exe**.

## Usar

Crie seus perfis, abra os jogos nos cartões e escolha o modo de grade. Para espelhar, deixe as contas na mesma tela do jogo e use **Alinhar → Espelhar**. **Parar** ou **Esc** encerra o espelhamento.

Encontrou um problema? [Abra uma issue](https://github.com/lisarbjoao/ZasaBoard/issues).
